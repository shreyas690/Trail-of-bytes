Trail of Bytes is a MERN stack–based web application that delivers a gamified treasure hunt combined with coding challenges. The platform is designed to promote problem-solving, teamwork, and logical thinking through a structured, multi-level competition format.Key Features
Admin Game Control
Admin can initiate and manage game sessions
Ability to control question flow and monitor team performance
Team-Based Authentication
Teams log in using a Team ID and Team Name
Enables secure participation and score tracking
Level 1: Treasure Hunt Quiz
Players solve logic and puzzle-based questions
Correct answers reveal tiles on a hidden treasure grid
Teams can open revealed tiles to uncover rewards
Incorrect attempts result in a 50-point penalty
Points are awarded based on question difficulty
Level 2: Coding Challenge
Players are automatically redirected after completing Level 1
Participants select coding questions and provide the correct output
Answers are validated through backend logic and scores are updated accordingly
Dynamic Scoring System
Difficulty-based point allocation
Automated penalty deductions
Real-time score updates
Automatic Level Progression
Seamless transition between quiz and coding rounds
Technology Stack
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
Tools & Concepts: REST APIs, Git, GitHub
Objective
The objective of Trail of Bytes is to create an engaging platform that integrates learning with competition. It can be used in technical events, hackathons, or academic environments to encourage collaborative problem-solving and coding practice in an interactive format.
Future Enhancements
